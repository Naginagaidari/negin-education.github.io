# Negin Educational Center

Official website of Negin Educational Center for Children with Disabilities in Afghanistan.

## About

Negin Educational Center is dedicated to supporting children with disabilities
through education, learning opportunities, and an inclusive environment.

This repository contains the source code for the center's official website.

## 🌐 Website

Visit the live website:

https://naginagaidari.github.io/negin-education.github.io/

## 🎯 Purpose

The website provides information about:

- Negin Educational Center
- Educational programs and activities
- Resources for children and families
- The center's mission and work
- Ways to support and collaborate

- CSS
- JavaScript
